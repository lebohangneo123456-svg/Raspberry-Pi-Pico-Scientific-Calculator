# Project Notes

## Project Title
Raspberry Pi Pico Scientific Calculator

## Summary
This project is a Proteus simulation of a calculator using a Raspberry Pi Pico, a calculator keypad, and an I2C LCD. The firmware is written in MicroPython and supports the core arithmetic functions.

## What Was Completed
- Calculator circuit wired in Proteus
- Keypad interfacing through GPIO pins
- I2C LCD interfacing through GP0 and GP1
- Fast-response firmware created
- LCD screen behavior improved to hide old input automatically
- Result display verified in simulation screenshots

## Current Capability
The current version supports:
- Addition
- Subtraction
- Multiplication
- Division
- Clear function
- Result display

## Notes
The repository includes the original Proteus project, firmware, screenshots, README, and license.
